# PWA Fase 1 (instalável na tela inicial) Implementation Plan

> **For agentic workers:** implementar tarefa a tarefa. Steps usam checkbox (`- [ ]`).
> **Sem framework de testes neste projeto:** a "verificação" de cada tarefa é `npm run build`
> e checagem no navegador (leitura de DOM/JS no preview), como nas ondas anteriores.

**Goal:** deixar o Zênite instalável na tela inicial do iPhone, abrindo em tela cheia com ícone próprio.

**Architecture:** Web App Manifest (rota do Next) + meta/ícones específicos da Apple no layout +
conjunto de ícones gerado por script (sharp) + dica de instalação para iOS (Safari não tem prompt).

**Tech Stack:** Next 16 App Router (`MetadataRoute.Manifest`, `Viewport`), sharp, Tailwind, lucide-react.

### Task 1: Gerar o conjunto de ícones PWA

**Files:**
- Create: `scripts/gen-pwa-icons.mjs`
- Create (gerados): `public/icons/icon-192.png`, `public/icons/icon-512.png`,
  `public/icons/icon-512-maskable.png`, `public/icons/apple-touch-icon.png`

**Interfaces:**
- Produces: os 4 arquivos PNG em `public/icons/` usados pelo manifest (Task 2) e pelo layout (Task 3).

- [ ] **Step 1: criar o script** `scripts/gen-pwa-icons.mjs`

```js
import sharp from "sharp";
import { mkdirSync } from "node:fs";

const BG = { r: 8, g: 11, b: 18, alpha: 1 }; // #080b12 (marca)
const LOGO = "public/logo.png"; // emblema branco transparente (gerado por gen-logo.mjs)

mkdirSync("public/icons", { recursive: true });

async function icon(size, out, pad) {
  const inner = Math.round(size * (1 - pad * 2));
  const emblem = await sharp(LOGO)
    .resize(inner, inner, { fit: "contain", background: { r: 0, g: 0, b: 0, alpha: 0 } })
    .toBuffer();
  await sharp({ create: { width: size, height: size, channels: 4, background: BG } })
    .composite([{ input: emblem, gravity: "center" }])
    .png()
    .toFile(out);
  console.log("wrote", out, `${size}x${size}`);
}

await icon(192, "public/icons/icon-192.png", 0.16);
await icon(512, "public/icons/icon-512.png", 0.16);
await icon(512, "public/icons/icon-512-maskable.png", 0.28); // safe zone maior
await icon(180, "public/icons/apple-touch-icon.png", 0.16);  // iOS arredonda os cantos
console.log("PWA icons OK");
```

- [ ] **Step 2: rodar o script**

Run: `node scripts/gen-pwa-icons.mjs`
Expected: imprime "wrote ..." para os 4 arquivos + "PWA icons OK".

- [ ] **Step 3: conferir os arquivos**

Run: `ls -la public/icons`
Expected: os 4 PNGs presentes, não vazios.

- [ ] **Step 4: commit**


### Task 4: Dica de instalação para iOS

**Files:**
- Create: `src/components/pwa/ios-install-hint.tsx`
- Modify: `src/app/(app)/layout.tsx` (renderizar o hint no `<main>`, junto do `NotificationBanner`)

**Interfaces:**
- Produces: componente `IosInstallHint` (client) que aparece só em iOS Safari fora do standalone.

- [ ] **Step 1: criar** `src/components/pwa/ios-install-hint.tsx`

```tsx
"use client";

import { useEffect, useState } from "react";
import { Share, X } from "lucide-react";

export function IosInstallHint() {
  const [show, setShow] = useState(false);

  useEffect(() => {
    const ua = window.navigator.userAgent;
    const isIOS = /iphone|ipad|ipod/i.test(ua);
    const isSafari = isIOS && !/crios|fxios|edgios/i.test(ua); // exclui Chrome/Firefox/Edge no iOS
    const standalone =
      window.matchMedia("(display-mode: standalone)").matches ||
      (window.navigator as unknown as { standalone?: boolean }).standalone === true;
    const dismissed = localStorage.getItem("ios-install-hint-dismissed") === "1";
    if (isSafari && !standalone && !dismissed) setShow(true);
  }, []);

  if (!show) return null;

  function dismiss() {
    localStorage.setItem("ios-install-hint-dismissed", "1");
    setShow(false);
  }

  return (
    <div className="glass mb-4 flex items-center gap-3 rounded-2xl border border-border p-4">
      <Share className="h-5 w-5 shrink-0 text-primary" />
      <p className="flex-1 text-sm text-muted-foreground">
        Instale o Zênite no seu iPhone: toque em{" "}
        <span className="font-medium text-foreground">Compartilhar</span> e depois em{" "}
        <span className="font-medium text-foreground">Adicionar à Tela de Início</span>.
      </p>
      <button
        onClick={dismiss}
        aria-label="Dispensar"
        title="Dispensar"
        className="rounded-lg p-2 text-muted-foreground hover:bg-accent"
      >
        <X className="h-4 w-4" />
      </button>
    </div>
  );
}
```
