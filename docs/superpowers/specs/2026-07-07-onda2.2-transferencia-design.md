## 1. Objetivo
Permitir registrar uma **transferência entre contas**: sai da conta origem e entra na conta destino, sem
contar como receita nem despesa do mês (é só movimento interno). Sugestão #8.

## 2. Modelo (espelha o padrão de "pagamento de fatura")
Uma transferência cria **2 lançamentos** ligados por um `transfer_group` (uuid), ambos `is_transfer=true`:
- **saída:** `type=expense`, `bank_id=<origem>`, `category_id=null`, `card_id=null`, `is_card_payment=false`.
- **entrada:** `type=income`, `bank_id=<destino>`, `category_id=null`.
- Mesma `description`, `amount` e `occurred_on` nos dois.

**Invariantes:**
- **Saldos:** o cálculo de saldo do banco (`data/finance.ts`) já soma todas as transações por conta
  (income +, expense −), então a saída reduz a origem e a entrada aumenta o destino **automaticamente** —
  nenhuma mudança no cálculo de saldo.
- **Totais do mês:** Receitas e Despesas passam a **excluir `is_transfer`** (não é ganho nem gasto).
- **Quebra por categoria:** também exclui `is_transfer` (transferências não têm categoria).

## 3. Fora de escopo (YAGNI)
- Transferência de/para cartão (a #8 é entre **contas** bancárias; pagamento de fatura já existe).
- Editar uma transferência já criada (MVP: excluir e recriar). Assinaturas recorrentes (#7) é outro sub-projeto.

## 4. Backend
- **Migração `supabase/migrations/20260701000009_tx_transfer.sql`:**
  `alter table public.transactions add column if not exists is_transfer boolean not null default false;`
  `alter table public.transactions add column if not exists transfer_group uuid;`
  `create index if not exists tx_transfer_group_idx on public.transactions (transfer_group);`
  `notify pgrst, 'reload schema';`
- **Tipos (`src/types/finance.ts`):** `Transaction` ganha `is_transfer: boolean; transfer_group: string | null`.
- **Validação (`src/lib/validation/finance.ts`):** `transferInput = z.object({ description (min 1),
  amount (positive), from_bank_id (int), to_bank_id (int), occurred_on (regex data) })` + refine
  `from_bank_id !== to_bank_id` ("Escolha contas diferentes").
- **Actions (`src/lib/actions/finance.ts`):**
  - `createTransfer(raw)`: valida Zod, `ctx()`, `randomUUID()` (já importado), insere as 2 linhas (saída +
    entrada) com o mesmo `transfer_group`, `revalidate()`.
  - `deleteTransferGroup(group: string)`: `delete ... eq("transfer_group", group)` + `revalidate()`.
- **Dados (`src/lib/data/finance.ts`):** nos totais, `income` filtra `type==="income" && !t.is_transfer`;
  `expense` filtra `type==="expense" && !t.is_card_payment && !t.is_transfer`.
- **Quebra por categoria (`src/app/(app)/financas/page.tsx`):** no loop `byCat`, adicionar `|| t.is_transfer`
  ao `continue` (pular transferências).

## 5. UI (`src/components/finance/transactions-section.tsx`)
- Estados novos: `isTransfer` (boolean), `toBankId` (string). Resetados em `reset()`.
- No modal, quando `type==="expense"`: um checkbox **"É transferência entre contas"** (ao lado/abaixo do de
  pagamento de fatura; **mutuamente exclusivos** — marcar um desmarca o outro). Quando `isTransfer`:
  - esconder categoria e cartão;
  - o campo **"Conta"** vira **"Conta origem"**;
  - aparece **"Conta destino"** (select de bancos, excluindo a origem).
- `save()`: se `isTransfer` (e não editando), validar origem/destino e chamar
  `createTransfer({ description, amount, from_bank_id: Number(bankId), to_bank_id: Number(toBankId),
  occurred_on: date })`; senão, fluxo atual. (Edição de transferência fora de escopo — o botão editar não
  abre transferência; ver §6.)
- **`TxRow`:** marcar linhas `is_transfer` com **"🔄 transferência"** (no lugar de categoria).
- `remove()`: se `t.transfer_group`, confirmar e chamar `deleteTransferGroup(t.transfer_group)`; senão o
  fluxo atual (que já trata `purchase_group`).

## 6. Edição (MVP)
Editar/excluir: **excluir** uma transferência remove os 2 lançamentos (`transfer_group`). **Editar** uma linha
de transferência pelo lápis abre o modal normal, mas como é confuso editar meia transferência, o MVP:
o `openEdit` de uma linha com `transfer_group` mostra um `toast` "Para alterar uma transferência, exclua e
recrie" e não abre o modal. (Simples e sem ambiguidade.)
